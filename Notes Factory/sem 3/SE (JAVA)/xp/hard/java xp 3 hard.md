## Experiment No. 3

### Aim:

To develop a Java program demonstrating **default, parameterized, and copy constructors** for object initialization in a Urine Test Strip diagnostic system.

### Objective:

1.  To understand default and parameterized constructors.
    
2.  To implement copy constructors in Java.
    
3.  To initialize diagnostic device objects using constructors.
    
4.  To understand object initialization through constructors.
    
5.  To apply constructors to Patient and Test Strip components.
    

### Software Used:

-   Java Development Kit (JDK)
    
-   Visual Studio Code
    
-   Command Prompt / Terminal
    
-   Java Compiler (`javac`)
    

### Theory:

A **constructor** is a special method used to initialize objects in Java. A default constructor initializes an object with default values, while a parameterized constructor initializes it using given values. A copy constructor creates a new object using the values of an existing object.

In this experiment, constructors are used to initialize **Patient, Test Strip, and diagnostic device information** such as Patient ID, Strip ID, Test Date, Device ID, and reagent information.

### Outcome:

The program successfully demonstrates **default, parameterized, and copy constructors** for initializing diagnostic system objects.

### Conclusion:

The experiment successfully demonstrates different types of constructors in Java and their use in initializing objects for a urine test strip diagnostic system.
