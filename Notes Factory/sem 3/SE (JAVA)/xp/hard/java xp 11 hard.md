### AIM

Design Graphical User Interfaces (GUI) using AWT components and layouts.

### OBJECTIVE

- To understand GUI development using Java AWT.
- To use AWT components and layout managers.
- To develop a patient registration interface.

### SOFTWARE USED

- JDK 17
- Visual Studio Code
- Command Prompt / Terminal

### THEORY

AWT (Abstract Window Toolkit) is a Java library used to create graphical user interfaces.

Components such as Label, TextField, Button, and TextArea accept input and display information. Layout managers arrange components inside a window.

### OUTCOME

A patient registration interface was successfully developed using Java AWT components and layouts.

### CONCLUSION

Thus, a graphical user interface was successfully designed using Java AWT for patient registration and sample information entry.
