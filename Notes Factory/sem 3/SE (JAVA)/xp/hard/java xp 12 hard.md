### AIM

Develop interactive Java GUI applications using event handling mechanisms.

### OBJECTIVE

- To understand event handling in Java.
- To use buttons and event listeners in a GUI application.
- To implement Capture Test, Analyze, Generate Report, and Reset buttons.

### SOFTWARE USED

- JDK 17
- Visual Studio Code
- Command Prompt / Terminal

### THEORY

Event handling in Java allows a program to respond to user actions such as button clicks.

The `ActionListener` interface handles button click events, and the `actionPerformed()` method executes when a registered button is clicked.

In this program, an interactive diagnostic report generator is developed using Java AWT. The buttons capture test details, display analysis status, generate a diagnostic report, and reset the interface.

### OUTCOME

An interactive diagnostic report generator was successfully developed using Java AWT and event handling mechanisms.

### CONCLUSION

Thus, a Java GUI application was successfully implemented using AWT components and event handling to respond to button clicks and update diagnostic status.
