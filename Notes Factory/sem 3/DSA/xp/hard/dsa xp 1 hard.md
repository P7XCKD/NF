## Experiment No. 1

### Aim:

To implement a Patient Diagnostic Alert System using Stack operations.

### Objective:

To manage patient diagnostic alerts using Push, Pop, and Display operations.

### Software Used:

C Language

### Theory:

A stack is a linear data structure that follows **LIFO (Last In First Out)**. In this program, abnormal glucose, protein, and pH values generate alerts that are stored using Push. Pop removes the latest alert, and Display shows active alerts.

### Outcome:

The Patient Diagnostic Alert System was successfully implemented using Stack operations.

### Conclusion:

The program demonstrates the use of Stack, Push, Pop, Display, conditional statements, and user input for managing patient diagnostic alerts.
