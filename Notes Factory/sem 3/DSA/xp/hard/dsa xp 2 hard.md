# DSA Experiment 2

### Aim:

To implement a Linear Queue using an array.

### Objective:

-   To implement a Linear Queue using an array.
    
-   To perform Insert, Delete, and Display operations.
    
-   To understand FIFO (First In First Out) behavior.
    
-   To handle Overflow and Underflow conditions.
    

### Software Used:

-   DOSBox
    
-   Turbo C++
    

### Theory:

A Linear Queue is a linear data structure that follows the **FIFO (First In First Out)** principle. Insertion is performed from the `rear` and deletion is performed from the `front`. An array is used to store the queue elements. The program handles Overflow when the queue is full and Underflow when the queue is empty.

### Outcome:

The Linear Queue was successfully implemented using an array. Insert, Delete, and Display operations were performed according to the FIFO principle.

### Conclusion:

The program demonstrates the implementation of a Linear Queue using an array and handling of Overflow and Underflow conditions.
