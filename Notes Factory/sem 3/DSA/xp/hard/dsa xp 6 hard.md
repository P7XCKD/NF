### DSA Experiment 6

### AIM
To Implement Binary Tree and its Traversal for real-world application

### OBJECTIVE
To understand binary tree structure and implement Inorder, Preorder, and Postorder traversal techniques.

### THEORY
A **Binary Tree** is a non-linear data structure in which each node can have at most two children: left and right. Traversal techniques are used to visit all nodes in a specific order.

### ALGORITHMS

**1. Create a Binary Tree**
1. Create a new node.
2. Store the data in the node.
3. Create its left and right child nodes.
4. Repeat until all required nodes are created.

**2. Inorder Traversal (Left, Root, Right)**
1. Traverse the left subtree.
2. Display the root node.
3. Traverse the right subtree.

**3. Preorder Traversal (Root, Left, Right)**
1. Display the root node.
2. Traverse the left subtree.
3. Traverse the right subtree.

**4. Postorder Traversal (Left, Right, Root)**
1. Traverse the left subtree.
2. Traverse the right subtree.
3. Display the root node.

### OUTCOME
A binary tree was implemented successfully, and Inorder, Preorder, and Postorder traversal techniques were performed.

### CONCLUSION
Thus, binary tree construction and traversal techniques were implemented and studied successfully.
