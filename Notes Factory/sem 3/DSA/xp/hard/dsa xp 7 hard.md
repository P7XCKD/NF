### THEORY:

A **Graph** is a non-linear data structure consisting of vertices (nodes) and edges connecting them. Graph traversal is the process of visiting vertices in a systematic manner.

Two common graph traversal techniques are:

- **Breadth First Search (BFS):** Visits adjacent vertices level by level using a queue.
- **Depth First Search (DFS):** Visits a vertex and explores as far as possible along each path before backtracking, using recursion or a stack.

Graph traversal is used in social networks, navigation systems, network routing, and pathfinding applications.

### ALGORITHM:

1. Start.
2. Represent the graph using an adjacency matrix or adjacency list.
3. Select a starting vertex.
4. Mark the starting vertex as visited.
5. Visit the adjacent unvisited vertices using the selected traversal technique.
6. Continue until all reachable vertices have been visited.
7. Display the traversal order.
8. Stop.
