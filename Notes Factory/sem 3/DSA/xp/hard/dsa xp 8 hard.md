### AIM:

Implementation of any one Sorting Technique considering a real-world application.

### THEORY:

Sorting is the process of arranging data in a particular order.

**Bubble Sort** is a sorting technique that compares adjacent elements and swaps them if they are in the wrong order. This process repeats until the elements are sorted.

Bubble Sort is used for arranging marks, temperatures, prices, and other numerical data. In temperature monitoring, it can arrange weather station temperature readings in ascending order for easier analysis.

### ALGORITHM:

1. Start.
2. Read the number of temperature readings.
3. Input the temperature readings into an array.
4. Compare each pair of adjacent elements.
5. If the first element is greater than the second, swap them.
6. Repeat the process until all elements are sorted.
7. Display the sorted temperatures in ascending order.
8. Stop.

### OUTCOME:

Bubble Sort was implemented successfully in C to arrange numerical data in ascending order. A temperature monitoring use case was also demonstrated by sorting temperature readings.
