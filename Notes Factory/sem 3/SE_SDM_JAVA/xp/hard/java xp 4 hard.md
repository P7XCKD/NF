## Experiment No. 4

### Aim:
To develop a Java program using one-dimensional arrays to store and analyze multi-parameter urine test results.

### Objective:
1. To understand the use of one-dimensional arrays in Java.
2. To store urine test parameters and their values using arrays.
3. To compare test values with their normal ranges.
4. To identify and count abnormal parameters.
5. To calculate the average value of the tested parameters.
6. To determine the severity level based on abnormal parameters.

### Software used:
- Java Development Kit (JDK)
- Visual Studio Code
- Command Prompt / Terminal
- Java Compiler (`javac`)

### Theory:
An array is a collection of elements of the same data type stored under a single variable name. A one-dimensional array stores data in a linear sequence and is accessed using an index.

In this experiment, arrays are used to store urine analyte names, their test values, and their normal minimum and maximum values. Each test value is compared with its normal range to determine whether it is normal or abnormal. The program then calculates the number of abnormal parameters, average value, and severity level.

### Outcome:
The program successfully uses one-dimensional arrays to store and analyze urine test parameters. It identifies abnormal values, counts abnormal parameters, calculates the average value, and determines the severity level.

### Conclusion:
The experiment successfully demonstrates the use of one-dimensional arrays in Java for storing, processing, and analyzing multiple urine test parameters.
