### Experiment No. 7:

### Aim:

Develop modular Java applications using packages and interfaces to implement abstraction and code reusability.

### Objective:

To create a modular healthcare application using packages and interfaces.

### Software Used:

- Java Development Kit (JDK)
- Visual Studio Code

### Theory:

Java packages are used to organize classes into separate modules. Interfaces provide abstraction and code reusability by defining methods that can be implemented by different classes.

In this experiment, `patient`, `diagnostic`, and `report` packages are used to develop a modular healthcare application. The `DiagnosticAnalyzer` interface is implemented by the `BloodTest` class.

### Outcome:

The modular healthcare application was successfully implemented using packages and interfaces.

### Conclusion:

The experiment demonstrates abstraction and code reusability using Java packages and interfaces.
