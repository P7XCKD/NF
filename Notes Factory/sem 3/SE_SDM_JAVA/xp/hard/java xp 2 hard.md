

## Experiment No. 2

### Aim:

To implement a Java program using **classes, objects, methods, and encapsulation** for a Patient and Test Strip Management System.

### Objective:

1.  To understand classes and objects.
    
2.  To implement constructors and methods.
    
3.  To understand encapsulation using private data members.
    
4.  To create relationships between classes.
    
5.  To determine the overall health status from test results.
    

### Software Used:

-   Java Development Kit (JDK)
    
-   Visual Studio Code
    
-   Command Prompt / Terminal
    
-   Java Compiler (`javac`)
    

### Theory:

Java is an object-oriented programming language that supports **classes, objects, constructors, methods, and encapsulation**.

In this experiment, the `Patient` class stores patient details, while the `TestStrip` class stores glucose, protein, pH, and blood type. The `DiagnosticReport` class combines these objects to generate the final report.

Private data members demonstrate **encapsulation**, while constructors initialize objects and methods display information and calculate health status.

> Note: The given test ranges are simplified values used only for demonstrating Java programming concepts.

### Outcome:

The program successfully demonstrates **classes, objects, constructors, methods, encapsulation, and interaction between multiple classes** to generate a diagnostic report.

### Conclusion:

The experiment successfully demonstrates the use of **object-oriented programming concepts in Java** through a simple Patient and Test Strip Management System.
