### AIM

Develop applications using Java File I/O streams for reading, writing, and processing structured data files.

### OBJECTIVE

To develop a Java application for patient report storage using file handling, accepting patient details, storing records in text files, and generating diagnostic reports using Java I/O streams.

### SOFTWARE USED

Java, JDK, VS Code

### THEORY

File handling allows Java programs to read and write data using files. In this experiment, patient details are accepted from the user and stored in `patient_records.txt`.

The `FileWriter` and `BufferedWriter` classes are used to write patient records and generate the diagnostic report. The `FileReader` and `BufferedReader` classes are used to read the stored records line by line.

The program copies the patient records into `diagnostic_report.txt`. The `FileWriter` automatically creates the file if it does not exist and overwrites its contents if it already exists.

### OUTCOME

Patient details were successfully accepted from the user, stored in a text file, and copied into a diagnostic report using Java File I/O streams.

### CONCLUSION

Thus, Java File I/O was successfully implemented to accept, store, read, and process patient records and generate a diagnostic report using text files.
