### Experiment No. 1

### Aim:

To write a Java program using variables, operators, and decision-making statements to analyze basic urine test parameters and classify the result as **Normal** or **Abnormal**.

### Objective:

-   To use variables and the `Scanner` class for input.
    
-   To apply relational and logical operators.  
-   To implement `if-else` statements.
-   To compare String values using `.equals()`.
    
-   To classify urine test results based on given conditions.
    

### Software Used:

-   **Java Development Kit (JDK)**
    
-   **Visual Studio Code / Command Prompt**
    
-   **Java Compiler (`javac`)**
    

### Theory:

Java provides fundamental features such as variables, operators, input/output, and control statements. In this program, `Scanner` is used to accept glucose, protein, pH, and blood type as inputs.

Relational operators compare numerical values, while `&&` and `||` combine multiple conditions. The `if-else` statement classifies the overall result as **Normal** or **Abnormal** based on the given conditions.

### Outcome:

The program successfully accepts urine test parameters and classifies the overall report as **Normal** or **Abnormal**.

### Conclusion:

The experiment demonstrates the use of Java fundamentals such as variables, user input, operators, String comparison, and `if-else` statements to solve a simple real-world problem.
