## GROUP 1 — CHAPTER 1

**Database System Concepts and Architecture**  
**Weightage: 8 Marks**

**Prepare any 3 of the following predicted questions:**

1.  **Explain Three-Schema Architecture with diagram and example, including Internal, Conceptual and External levels.**
2.  **Explain DBMS Architecture with a suitable diagram.**
3.  **Explain in detail Data Independence with diagram and example. Explain Logical and Physical Data Independence.**

**Backup Questions:**

-   Differentiate File System and Database System.
-   Explain the drawbacks of the File System.
-   Explain the advantages of a Database System over File System.
-   Explain different types of Database Users.
-   Explain functions/responsibilities of Database Administrator (DBA).
-   Explain Two-Level and Three-Level Architecture with diagram.
-   Explain applications of DBMS.
-   Explain the Heatwave Intelligence System scenario and how DBMS overcomes limitations of maintaining meteorological observations using separate files.
-   Explain how Three-Schema Architecture can provide different database views for citizens, farmers, health agencies and local authorities.
-   Explain how Data Independence, Data Integration, Data Consistency and Centralized Data Management can be achieved in a Heatwave Intelligence System.

## GROUP 2 — CHAPTER 2

**Entity Relationship Data Model**  
**Weightage: 8 Marks**

**Prepare any 3 of the following predicted questions:**

1.  **Explain Specialization and Generalization with suitable examples.**
2.  **Explain Overlapping and Disjoint constraints. Also explain Total and Partial Participation constraints.**
3.  **Design an ER diagram and relational schema for a given real-world system, identifying entities, attributes and relationships.**

**Backup Questions:**

-   Explain different types of attributes in an ER diagram.
-   Explain Stored Attribute and Derived Attribute with examples.
-   Define Entity Type, Entity Set, Weak Entity, Regular Entity, Total Participation and Partial Participation.
-   Define Primary Key, Foreign Key, Candidate Key and Super Key with examples.
-   Explain various mapping rules to convert EER into Relational Schema with example.
-   Explain Aggregation with example.
-   Compare Weak Entity and Strong Entity with example and diagram.
-   Design an ER diagram for a Climate Monitoring System containing regions, weather stations, temperature observations, heatwave forecasts, hotspots and advisories.
-   Design an ER diagram for the Urine Sample/Test/Parameter system.
-   Design an ER diagram and relational schema for the Sugarcane Procurement Management System.

***

## GROUP 3 — CHAPTER 3

**Relational Model and Relational Algebra**  
**Weightage: 4 Marks**

**Prepare any 3 of the following predicted questions:**

1.  **Write the syntax and example of Selection, Projection, Rename and Set Intersection operations in Relational Algebra.**
2.  **Write the syntax and example of Join, Division, Difference and Intersection operations in Relational Algebra.**
3.  **Write Relational Algebra expressions for a given set of relations and queries.**

**Backup Questions:**

-   Explain Cross Join, Equi Join and Outer Join with syntax and examples.
-   Explain Aggregate Functions with Relational Algebra notation and examples.
-   Solve Relational Algebra queries based on the Heatwave Intelligence System relations.
-   Solve Relational Algebra queries based on the Urine Strip Analysis System relations.
-   Solve Relational Algebra queries based on the Sugarcane Farm and Mill Management System.
-   Convert a given ER diagram into a Relational Model using Codd's rules.

# Preparation Strategy

1.  Complete the **predicted questions** first.
