## GROUP 1 — CHAPTER 1
**Computer Organization and 8086 Architecture**  
**Weightage: 8 Marks**

**Prepare any 3 of the following predicted questions:**

1. Describe any five addressing modes of the 8086 microprocessor.
2. Draw and explain the 8086 microprocessor architecture, including the Bus Interface Unit (BIU) and Execution Unit (EU).
3. Explain the flag register of the 8086 microprocessor.

**Backup Questions:**
- Describe the block-level description of the functional units of a computer.
- Explain the Von Neumann architecture in detail.
- Compare computer organization and computer architecture.
- Explain the Bus Interface Unit (BIU).
- Explain the Execution Unit (EU).
- Explain the performance measures of computer architecture.

## GROUP 2 — CHAPTER 2
**Instruction Formats, Instruction Cycle and Control Unit**  
**Weightage: 8 Marks**

**Prepare any 3 of the following predicted questions:**

1. What are the stages involved in the basic instruction cycle? Explain each stage in detail with a suitable diagram.
2. Given the expression `X = A[B + C(D + E)] / F(G + H)`, write a program to evaluate the expression using one-address instructions.
3. Briefly illustrate the instruction cycle state diagram with interrupts.

**Backup Questions:**
- Explain various instruction formats.
- Draw and explain the basic instruction cycle with interrupt processing.
- Explain how `X = A × B + C × C` is executed in one-address, two-address and three-address processors in an accumulator organization.
- Explain Flynn's classifications in detail.
- Explain data parallelism and its relationship to Flynn's classifications.
- Illustrate six-stage pipelining.
- Explain the hardwired control unit.
- Explain the softwired (microprogrammed) control unit.
- Differentiate between hardwired and softwired control units.

**Note:** The four questions separately labelled *Out of Syllabus* in the supplied material are excluded from this predicted shortlist unless the teacher confirms otherwise.

## GROUP 3 — CHAPTER 3
**Number Systems, Booth's Algorithm and Restoring Division**  
**Weightage: 4 Marks**

**Prepare any 3 of the following predicted questions:**

1. Solve a numerical on number-system conversions.
2. Using the restoring division algorithm for unsigned integers, divide 13 by 4 or 22 by 5.
3. Explain Booth's multiplication algorithm with a flowchart and solve a multiplication example.

**Backup Questions:**
- Explain the digital logic gates: NOT, AND, OR, NAND, NOR, EX-OR and EX-NOR.
- Apply Booth's algorithm to multiply 7 and 5.
- Multiply 5 and 10 using Booth's algorithm.
- Represent a given number in single-precision and double-precision floating-point formats.
